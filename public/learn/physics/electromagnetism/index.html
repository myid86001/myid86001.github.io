第九章 / 从整体通量，到局部场强

高斯定理：选对一个“包围面”

截图标为重点目标：会选面、会分区域对应练习卷 1—5、8 题

想象用一个封闭的、看不见的面把电荷包起来。我们关心电场从这个面净穿出去多少：向外穿出算正，向内穿入算负。这就是电通量。它不是数电场线的根数，而是对每个小面片上的电场法向分量求和。

∮SE·dS=Q内ε0

右边的 Q内 是面内正负相加后的净电荷。面外电荷也会产生电场，但它对闭合面的净通量贡献为零。左边的电场仍然是全部电荷共同产生的场。

为什么不能一上来就写 E × 面积？因为不同位置的场强可能大小不同、方向也不同。只有对称性足够好，才能把积分化成简单乘法。“定理成立”和“用它容易求场”是两件事。

从最小的电荷模型开始

两个静止点电荷的作用力大小 F = k|q₁q₂|/r²，同号排斥、异号吸引。定义场强 E = F/q试探（试探电荷足够小，不扰动原分布）；点电荷场强大小 k|q|/r²，正电荷向外、负电荷向内。多个源电荷的电场按矢量叠加。

电场线的切线表示场方向，疏密反映强弱；静电场线不会相交，否则同一点的场方向就不唯一。穿过面积元的通量为 dΦ = E dS cosθ，θ 是电场与面法线的夹角。均匀场穿平面才直接用 ES cosθ。

以均匀带电实心球为例

球的半径为 R，总电荷为正的 Q，均匀分布在整个体积里。没有其他电荷。你站在离球心 r 的地方，场有多强？

沿半径走一走

实线是 E 随 r 的变化。虚线圈是你选的高斯面，不是一层真实的材料。

面内电荷 / 总电荷0.125
场强 / 表面场强0.500

①

为什么选同心球面？

因为电荷分布没有偏爱的方向。距离球心相同的地方，场强大小相同；电场沿半径，恰好和球面的外法线同向。所以整个面上都可以用同一个 E，通量就是 E·4πr²。

②

球内只包住了一部分电荷

均匀分布意味着“电荷占比 = 体积占比”。小球体积与 r³ 成正比，所以 r 小于 R 时，面内电荷不是 Q，而是 Qr³/R³。

E·4πr2=Qε0r3R3⇒E=kQrR3(r<R)
③

球外包住全部电荷

再把高斯面放大，不会增加面内电荷，却会增加电通量分摊的面积。因此球外场强随着 r² 的增大而减小。

E=kQr2(r≥R)k=14πε0

验算比再背一遍更有用：球心处各方向相互抵消，E 应为零；在 r = R 处，球内外公式应给出相同结果；很远处应像一个点电荷。这三个检查都通过了。

当场试一题 / 新编基础题

r = R/2 和 r = 2R，哪边的场强更大？

先判断各点位于哪一个区域，再代公式。不要因为“更靠近球心”就直接套点电荷公式。

展开第一步：分别选公式

R/2 在球内，用 kQr/R³；2R 在球外，用 kQ/r²。

展开计算与答案
E(R/2)=kQ2R2,E(2R)=kQ4R2

所以前者是后者的 2 倍。如果错用了点电荷公式，会得到 16 倍；这就是分区域的价值。

第九章 / 用“能量高低”描述电场

电势：先选零点，再看落差

掌握目标：标量叠加、积分方向、正负号不是所有系统都能取无穷远为零

电场回答“正试探电荷放在这里会往哪里受力”；电势回答“每单位电荷在这里有多少电势能”。两者描述的是同一个静电场，但角度不同。把电势想成地势能帮你记方向：正电荷受电场力的方向，就是电势下降最快的方向。负电荷的受力方向则相反。

Ua−Ub=∫abE·dlEx=−dUdx

从 a 沿电场走到 b，积分为正，所以 Uₐ 比 Uᵦ 高。一维式中的负号也在说同一件事：若 U 随 x 增大而下降，Eₓ 就朝正方向。

电势的零点能选，电势差不能随便改给整个空间的 U 都加上 100 V，导数不变，电场不变。零点是一把尺子的起点，不会改变物理。有限电荷分布常取 U(∞) = 0；无限长线电荷、无限大平面一般不能这样取。

两个电荷，为什么“场相加”却“势抵消”？

在 x = −a 放 +q，在 x = +a 放 −q。原点处，正电荷把试探正电荷向右推，负电荷把它向右拉，两份电场方向相同。电势却只需带正负号相加：+kq/a 和 −kq/a 抵消。于是这里 U = 0，E 却不为零。

U=kqrW=q(Ua−Ub)

做功式中 q 必须带正负号。正电荷向低电势移动时 W 为正；若换成负电荷，不能只看“高到低”，还要看 q 的负号。电势能变化 ΔEp = −W。

连续分布怎么积分？先找“共同的距离”

圆环轴线上一点到环上每个电荷元的距离都相同，电势就特别好算：U = kQ/√(R²+x²)。若直接算电场，你还要消去横向分量；先算电势，再用 Eₓ = −dU/dx，往往更省事。

①

画源点与观察点

积分变量属于电荷所在的位置，不一定是观察点坐标。写清 dq = λdl、σdS 或 ρdV。

②

电势先做标量积分

dU = k dq/r 中的 r 是源点到观察点的距离。只有这个距离处处相同，才可提到积分号外。

③

场强用导数，零点用题设

检查远处是否趋于零，以及对称位置的场是否相互抵消。不要因为求出了 U，就忘记说明参考零点。

空心均匀球壳内部 E = 0，为什么 U 不为零？

壳内电势处处相同，正好说明其空间变化率为零。取无穷远为零时，这个常量为 kQ/R。只有“没有变化”，不是“没有数值”。

2025 年计算题 13 同型 / 三个区域的电势

均匀带电球层：空腔、球层、球外分别写

半径 a、b 之间（a < b）均匀带体电荷密度 ρ，取 U(∞) = 0。不是导体，电荷固定分布在体积中。

先理解为什么要在观察点处分段

对半径 s 的薄球壳，dq = 4πρs²ds。若观察点位于这个薄壳外面，它的贡献为 k dq/r；若位于薄壳内部，它的贡献为 k dq/s。观察点处于带电层中时，两种薄壳同时存在，积分必须在 s = r 处分开。

展开三个区域的结果和检查

r ≥ b：U = ρ(b³−a³)/(3ε₀r)。

a ≤ r ≤ b：U = [ρ/(3ε₀)]·[r²−a³/r + 3(b²−r²)/2]。

r ≤ a：U = ρ(b²−a²)/(2ε₀)。

把 r = a、b 代入相邻公式，电势必须连续；空腔内为常数，所以 E = 0。也可以先用高斯定理求分段 E，再从无穷远分段积分，不能把一段的场强公式用到全部路径。

第十章 / 把题目的动作，翻译成约束

导体接地：固定的是电势，不是电荷

截图标为重点目标：会区分等势、零电势、电荷守恒对应练习卷 9—10 题

金属里有能够移动的电荷。如果材料内部还有电场，它们就会继续移动。所以一旦达到静电平衡，导体材料内部的电场必须为零，同一连通导体各处电势相同。

外壳带正电，内壳接地，内壳会带电吗？

两个同心薄导体球壳，半径 a < b。外壳带总电荷 Q，保持孤立；内壳接地。取无穷远电势为零，求内壳电荷 q。

先猜方向：外壳的正电荷会把内壳电势抬高。要让内壳电势降回零，内壳需要从大地获得负电荷。因此答案应当是负数。

第一步：内壳电势由谁贡献？

电势可以代数相加。内壳自己的贡献是 kq/a；外壳在整个内部空间产生的电势都是 kQ/b。这里把球壳视为很薄，并利用同心球对称性。

U内=kqa+kQb
第二步：把“接地”代进去
kqa+kQb=0⇒q=−Qab

负号符合刚才的判断。a < b，所以内壳电荷的绝对值小于 Q；例如 a/b = 1/2，内壳只需 −Q/2。

多问一步：外壳内外表面分别带多少电？

在外壳金属材料中取高斯面，材料内 E = 0，因此它包围的总电荷为零。内壳带 q，外壳内表面就必须带 −q。外壳总电荷仍是 Q，因此外表面为 Q+q。

取 a/b = 1/2：内壳 −Q/2，外壳内表面 +Q/2，外壳外表面 +Q/2。三个量分别检验，别把“外壳总电荷”误当成“外表面电荷”。

断开地线以后，旧条件不能一直沿用断开那一刻，电荷来不及跳变；但之后若改变附近电荷或几何关系，内壳的电势可以改变。后续应固定 q，不是继续固定 U = 0。

空腔内外，哪些结论不能混用？

“导体内部 E = 0”指金属材料内部，不是任意空腔。封闭空腔内没有电荷且达到静电平衡时，腔内场为零；腔内若有电荷 q，内表面总感应电荷为 −q，但空腔内通常存在电场。

孤立导体球半径 R、带电 Q，取无穷远为零：球外 E = kQ/r²（带方向）、U = kQ/r；球内 E = 0、U = kQ/R。若题目给表面电势 U₀，可先用 Q = U₀R/k，再求球外 E = U₀R/r²。

空腔感应电荷“总量确定”不等于“均匀分布”腔内点电荷不在中心时，内表面电荷一般不均匀。高斯定理直接给的是总量，不会自动给出局部分布。

第十章 / 介质也在响应电场

电介质：自由电荷之外，还有极化

掌握目标：分清 E、D、P会用介质高斯定理

绝缘材料不能像金属那样让电荷跨越整个物体自由流动，但内部正负电荷可以产生微小相对位移，或者已有电偶极子转向。这叫极化。许多微小变化叠加起来，材料表面会出现束缚电荷，并反过来改变原来的电场。

∮D·dS=Q自由，内D=ε0E+P

E 是真正决定电荷受力的电场；P 是单位体积的电偶极矩；D 把极化响应纳入定义，使高斯定理右边只需计算自由电荷。不要把 D 直接理解成“更强的电场”，它的单位也是不同的：E 用 V/m，D、P 用 C/m²。

有了介质，求场仍可以走两步

例如极板自由电荷 ±Q、面积 S，板间填满均匀线性介质。先用自由电荷求 D = Q/S；再用 D = εE 得 E = Q/(εS)。最后若问极化强度，用 P = D−ε₀E。这个顺序把自由电荷与束缚电荷分开，省掉直接处理束缚电荷分布的麻烦。

条件要跟公式一起记D = εE、P = ε₀χeE 用于线性、各向同性介质，且 ε = ε₀(1+χe)。高斯定理对 D 的积分形式不要求你先假设这些简单材料关系。

把能量“分配到空间”

电容器能量可以写成场能密度的积分：W = ∫w dV。在线性介质中 w = E·D/2；真空中 w = ε₀E²/2。场均匀时才可以直接乘体积，非均匀场要逐点积分。

第十二章 / 电流怎样产生磁场

求磁场：先看形状，再决定用哪个定律

掌握目标：毕奥—萨伐尔、安培环路、方向叠加真空稳恒情形

直电流的磁场不是沿着电流向前，而是绕着导线转。把右手拇指指向电流，弯曲的四指就是磁场方向。多个电流同时存在时，每一个都贡献磁场，最后仍需做矢量相加。

两个工具，各擅长什么？

毕奥—萨伐尔定律从每一小段电流出发，算它对观察点贡献多少磁场，再积分。这适合有限导线、圆弧或由若干段拼成的导线。

dB=μ04πIdl×r^r2

这里 r 是电流元到观察点的距离，带帽的 r 是该方向的单位矢量。叉乘同时包含方向和 sinθ：电流元如果正好指向观察点，对该点的贡献为零。

安培环路定理则把闭合路径上的磁场联系到穿过路径所围曲面的电流。无限长直导线、理想长螺线管这样的高度对称系统，用它很省力。

∮B·dl=μ0I穿过B=μ0I2πr

为什么长直导线能写 B·2πr？因为圆形环路上 B 大小处处相同，方向处处沿环路切线。换成有限导线，即使定理成立，也不能想当然把 B 从环路积分里提出。

环路外电流会不会影响路径上的磁场？会。右边只记“穿过的净电流”，但左边 B 是全部电流产生的总场。环路积分为零，也不能推出路径上 B 处处为零。这与电场高斯定理的陷阱非常相似。

把常见结果放在一起记

几何模型结果必须看清的条件
无限长直导线B = μ₀I/(2πr)r 是到导线的垂直距离。
圆心处的单匝完整圆环B = μ₀I/(2R)只是在圆心；R 为圆环半径。
圆心处的圆弧B = μ₀Iφ/(4πR)φ 以弧度计；连接线贡献另算。
圆环轴线上距中心 xB = μ₀IR²/[2(R²+x²)3/2]横向分量相消，只剩轴向。
长密绕螺线管内部B ≈ μ₀nI远离端部，n 是每单位长度匝数。

有限长度到底多长才算“无限”？

2025 年卷问过这个问题。中垂线上距导线 a 处，精确结果等于无限长结果乘 L/√(L²+4a²)。这个系数小于 1，说明两端被截掉后贡献变少。只有 L 远大于 a，系数才接近 1。下面第 26 题会实际算误差。

磁通是另一个容易混的量

穿过一个平面的磁通为 Φ = BS cosθ，θ 是磁场与面法线的夹角。闭合面的净磁通总为零：∮B·dS = 0。这表示磁感线没有孤立的起点终点，不是说磁场不存在。

电场高斯定理、磁场高斯定理、磁场安培定理，怎么分？

看积分的对象：前两者穿过闭合“面”，描述通量；安培定理沿闭合“线”，描述环流。电场通量右边有净电荷；磁场通量为零；稳恒磁场环流右边有穿过的电流。

均匀磁场中，闭合线圈各段合力可为零，却存在力矩。定义磁矩 m = NISn，法线由线圈电流的右手规则确定；力矩 τ = m×B，大小 mB sinθ。它使磁矩趋向与磁场同向。这里不要把“力为零”误认成“力矩为零”。

回旋加速器与霍尔效应，各用哪一点？

回旋加速器利用非相对论周期 T = 2πm/(|q|B) 不随速率变化。每圈获得相同能量时，r² 每圈增加相同量，r 的增量反而逐渐减小。磁场负责拐弯，电场负责加速。

霍尔效应利用横向磁力先把载流子挤向一侧，直到产生的横向电场力与磁力平衡。由 EH = vdB、I = n|q|vdwt，得到 |UH| = IB/(n|q|t)。t 是沿磁场方向的厚度，n 是单一载流子的数密度。电压符号还可反映载流子类型。

第十三章 / 材料本身也会磁化

磁介质：先分清三种响应

磁性分类：截图强调的重点掌握目标：概念、H/B/M、磁滞

线圈的自由电流产生磁场，放进去的材料也会作出磁响应。微观磁矩的变化，或者已有磁矩的取向改变，累加起来表现为宏观磁化强度 M。它表示单位体积的磁矩。

类型直观机制与方向怎么记
抗磁外场诱导的磁响应总体反向；χm 略小于零“反着一点”，常较弱。
顺磁原有磁矩倾向随外场排列，热运动扰乱排列；χm 略大于零“顺着一点”，普通情况下温度升高响应减弱。
铁磁磁畴中的磁矩协同排列，磁畴移动或转向带来强响应强、通常非线性，而且有历史依赖。

一般物质具有抗磁响应，但观察到的总磁性可能被更强的顺磁或铁磁响应盖过。因此“有抗磁机制”和“宏观表现为抗磁体”不是同一句话。

B=μ0(H+M)∮H·dl=I自由

H 让环路定理右边只记自由电流；B 是进入洛伦兹力的磁感应强度；M 描述材料的磁化。在线性各向同性模型下，M = χmH，B = μH，μ = μ₀(1+χm)。铁磁材料常不能用一个恒定 μ 走到底。

长螺线管填入介质，为什么先算 H？

线圈电流 I 与匝密度 n 已知，先由自由电流得 H = nI，再按材料关系得 M、B。若直接把真空的 μ₀nI 原封不动当作填介质后的 B，就漏掉了材料响应。

常规起手 / 线性介质

n = 1000 m⁻¹、I = 0.50 A、μr = 2。先算 H = 500 A/m，再算 χm = 1，所以 M = 500 A/m；最后 B = μ₀(H+M) ≈ 1.26 mT。

H 与 M 的单位为 A/m，B 的单位为 T。单位不同，不能把 B = H+M。

剩磁、矫顽力、磁滞：记成一段过程

先把材料磁化得很强，再把外加 H 降到零，B 仍保留的值叫剩磁；继续施加反向 H，直到 B 降为零，对应的反向场强大小叫矫顽力。正向和反向的路径不重合，形成磁滞回线；一周循环中的能量损耗与回线面积有关。

永久磁铁需要不易被消磁，通常选矫顽力大的硬磁材料；变压器铁芯需要反复磁化且少发热，通常选回线窄、损耗小的软磁材料。

历年磁化电流题，为什么在内表面容易判反？

磁化面电流密度 Kb = M×n，其中 n 是从磁介质指向外部的法线。介质包在导线外面时，“介质内表面”的外法线指向导线，而不是远离导线。把法线画对，再做叉乘，下面第 35 题会用到。

第十四章 / 磁通变化，电动势就出现

电磁感应：阻碍的是“变化”

掌握目标：磁通、楞次方向、动生与感生先说明正方向，再谈正负号

回路里有磁场并不自动意味着有感应电动势。关键是穿过回路的磁通有没有改变：磁场变、面积变、线圈转动，都可能做到。反过来，B 虽然变了，若穿过回路的磁通不变，仍不能凭 B 的变化直接判断电动势。

ξ=−NdΦBdtΦB=BScosθ

这里 ΦB 是每匝磁通，N 匝磁通相同才能直接乘 N。计算磁通时 θ 是 B 与所选面法线的夹角；回路正向与法线方向按右手规则配对。负号表达楞次定律，不是说电动势的数值永远为负。

向外的磁场，可以对应两种电流方向

在此刻 B 指向纸面外。回路静止，电阻为正，忽略自感。滑块改变的是这一时刻的磁场变化率，不是 B 本身的正负。

方向四步，每次都按这个顺序

①

原磁场朝哪里？

先标向里或向外，不急着画电流。

②

磁通在增加还是减少？

看穿过回路的量，面积变化时尤其不能只看 B。

③

感应磁场如何阻碍这个变化？

原磁通增加就反抗增加；原磁通减少就试图补回。所以感应磁场有时与原磁场同向。

④

右手从磁场回到电流

从纸面正面看：逆时针电流产生向外的磁场，顺时针产生向里的磁场。

动生：导体动，载流子被磁力推开

ξ=∫(v×B)·dl

直棒、速度、磁场满足相互垂直的标准情形，且 B、v 沿棒均匀时，电动势大小为 Bℓv。正电荷沿 v×B 方向被推，先据此判断哪端电势更高。若回路闭合，再用总电阻求 I。

转动棒各处速度不同：距转轴 r 处 v = ωr，所以要把 Bωr dr 从 0 积到 ℓ，得到 Bωℓ²/2。忘记积分、直接使用端点速度，是漏掉 1/2 的常见原因。

感生：导体不动，变化磁场产生涡旋电场

对固定回路，∮E·dl = −dΦB/dt。这个电场沿闭合回路可以有非零环流，因此不能简单套静电势差处理。感生电动势并不需要某根导体棒运动。

2025 年卷同型延伸 / 导体圆盘涡流

为什么把圆盘切成同心薄环？

半径 a、厚 b、电阻率 ρ 的圆盘，垂直盘面的均匀磁场满足 dB/dt = k。忽略感应电流自己的磁场。感生电场绕轴转，所以电流自然沿同心环流动。

第一步：半径 r 的小环有自己的电动势

环路包围面积 πr²，因此 |ξ(r)| = πr²|k|。半径越大，包围的变化磁通越多。

第二步：写环电阻，截面积别用 πr²

电流沿圆周流过，路径长 2πr；与电流垂直的导电截面是 b dr。所以 dR环 = ρ·2πr/(b dr)，小环中的电流为 dI = |ξ|/dR环 = b|k|r dr/(2ρ)。

第三步：总环流是所有薄环电流相加

对 r 从 0 积到 a：I总 = b|k|a²/(4ρ)。它表示穿过一条径向截面的总环流，不是从圆心流向边缘的电流。方向仍用楞次定律判断。

用能量再检查一次方向滑动导体棒的感应电流产生的磁力通常阻碍磁通的变化。标准匀速滑棒题中，外力做功率 Fv 等于 I²R；若你算出磁力无缘无故持续加速棒，就应回头查方向。

自感与 RL：电流不愿突然改变

线圈电流产生磁场，电流变化又使穿过线圈自身的磁通变化，于是线圈自己产生感应电动势。这就是自感。它不总是反对电流：电流增加时压住增加，电流减少时试图维持，反对的是变化。

对恒定 L 的线性线圈，磁链 Ψ = NΦ = LI。负号来自楞次定律。若采用电流流入端为电压正端的被动符号约定，电感端电压为 uL = L di/dt；别把它与反向的自感电动势符号混在一起。

接通电源的一瞬间，电流能到 ξ/R 吗？

不能。若初始电流为零，电感电流在有限电压下不能突变，所以 i(0+) = 0。过了很久，di/dt = 0，理想电感不再有电压降，最终电流才是 ξ/R。

互感：变化来自隔壁线圈

线圈 1 的电流变化，使穿过线圈 2 的磁链变化。在线性、位置固定的模型中，感应电动势大小为 M|di₁/dt|。方向或端子正负还要知道两线圈绕向与参考方向；只给 M 和变化率，通常只能唯一确定大小。

能量在哪里？在磁场里

线圈储能 W = LI²/2；线性介质中磁场能密度 w = B·H/2，真空中为 B²/(2μ₀)。场不均匀时要积分，不能随便用某一点的 B 乘全部体积。理想 RL 放电至零电流，初始磁能全部变为电阻热量。

若电流减半，线圈磁能剩多少？

L 恒定时 W 与 I² 成正比，所以只剩四分之一。这个平方关系与电容的 W = Cu²/2 对照着记。

五个口头检查 / 能说明理由比只报答案更好
1. 为什么无限大带电平面的场强里有 1/2？

薄柱高斯面的两个端面都有相同通量，所以总通量是 2ES，而不是 ES。

2. 圆台电阻为什么不能直接用平均面积？

电阻薄片串联，累加的是 ρdx/S(x)。平均 1/S 与用平均 S 的倒数一般不同。

3. 带电粒子速度加倍，回旋周期会加倍吗？

非相对论匀强磁场中不会。半径也加倍，路程与速率一起加倍，周期保持不变。

4. 线圈磁通最大时，感应电动势也最大吗？

不一定。匀速转动线圈中，磁通最大时导数为零，电动势恰好为零；电动势取决于变化率。

5. 一个磁化过的铁磁体，H = 0 时 B 一定为零吗？

不一定，可能存在剩磁。这正是简单线性关系 B = μH 不能普遍描述铁磁体的一个原因。
